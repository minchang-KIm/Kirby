# Privacy

Windsprig is a static, local-play game.

- **No account:** the game does not ask you to register, sign in, or provide identity information.
- **No analytics:** the shipped game contains no analytics, advertising, telemetry, or behavioral tracking.
- **No server save:** browser profiles stay in that browser's local storage, and Windows profiles stay under `%LOCALAPPDATA%/Windsprig`.
- **No intentional data transmission:** gameplay, settings, and save data are not intentionally sent to the developer or another service.

The hosting provider may process ordinary network metadata when serving the static game files under its own privacy terms. Opening an external GitHub support or download link is a separate navigation initiated by the player.
