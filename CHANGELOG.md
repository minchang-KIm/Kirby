# Changelog

All notable public changes to Windsprig are recorded here.

## [1.0.0] - 2026-07-11

- Shipped the complete six-world, 30-stage campaign with 90 stable Wind Motes and six multi-phase bosses.
- Added one-to-four-player local play with explicit join, leadership, shared-camera, gather, defeat, checkpoint, and respawn rules.
- Added six echo-ability families, deterministic combat, bilingual English/Korean presentation, and local-only profiles.
- Added original generated art, original generated music and sound effects, licensed Korean typography, and accessibility settings.
- Added reproducible browser and Windows release pipelines, release provenance, checksums, offline PWA behavior, and automated product journeys.
